Why

Problem

Agent frameworks hide control flow inside callbacks. When a run fails you get a stack trace, not a plan, and you cannot tell which step consumed the budget.

Idea

Model the run as an explicit DAG. Every step names a tool, declares dependencies, and references earlier outputs by path. The executor walks it deterministically and retries.

Boundary

An execution kernel, not a model wrapper. Tools are plain callables, the planner is rule-based, and no network call happens anywhere.
